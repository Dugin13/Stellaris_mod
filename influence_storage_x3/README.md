# Influence Storage x3

This Stellaris mod increases influence storage to 3x vanilla by applying a permanent country modifier.

## What it changes

- Adds `country_resource_max_influence_add = 2000`
- Effective vanilla base influence cap changes from 1000 to 3000

## Files

- `common/static_modifiers/00_influence_storage_x3.txt`
- `common/on_actions/influence_storage_x3_on_actions.txt`
- `events/influence_storage_x3_events.txt`

## Notes

- This mod is lightweight and does not touch vanilla UI, technologies, or traditions.
- Compatible with most mods unless another mod overwrites the same on_actions/event behavior or influence cap in a conflicting way.
