# Imperial Corporate Authority Mod for Stellaris

This mod adds a new government authority called **Imperial Corporate** that combines corporate mechanics with hereditary succession (like Imperial authority).

## Features
- New authority: Imperial Corporate
- Uses heir succession instead of elections
- Combines corporate bonuses with imperial stability
- +20% Naval Capacity
- -20% Crime
- +20% Administrative Capacity

## Installation
1. Copy the `imperial_corporate_mod` folder to your Stellaris mod directory:
   - Windows: `%USERPROFILE%\Documents\Paradox Interactive\Stellaris\mod\`
2. Copy `descriptor.mod` to the same location and rename it to `imperial_corporate_mod.mod`
3. Enable the mod in the Stellaris launcher

## Usage
When creating a new empire:
1. Select "Imperial Corporate" as your authority
2. The government will function like a corporation but with hereditary succession
3. You'll have an heir instead of elections

## Compatibility
- Designed for Stellaris 3.x.x
- Should be compatible with most other mods
- May conflict with mods that heavily modify government authorities

## Notes
The authority requires capitalist ethics to be selected during empire creation.
