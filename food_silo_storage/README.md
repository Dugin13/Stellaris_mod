# Food Silo Storage

## Description
Adds a colony building that increases only food storage.

## Added Building
- **Food Silo** (`building_food_silo`)
- Effect: +5000 food storage only
- Cost: 500 minerals
- Upkeep: 2 energy
- Buildable on normal colonies

## Compatibility
- **Game Version**: Stellaris v4.x
- **Conflicts**: Mods that override `building_food_silo`
