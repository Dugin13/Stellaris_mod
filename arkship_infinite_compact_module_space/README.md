# Arkship Infinite Compact Module Space

## Description
Adds a repeatable planet decision for arkship colonies that grants +1 district slot by adding one Compact Module Space deposit each time.

## What It Does
- Adds a new decision: **Install Compact Module Space**
- Decision can be used on arkship colonies only
- Each use adds `d_compact_modules` (+1 max district)
- Can be used infinitely (no once-only lockout)

## Decision Cost
- 500 Alloys per use

## Compatibility
- Game version: Stellaris v4.x
- DLC required: Nomads (arkships)
- Save compatible: Yes
