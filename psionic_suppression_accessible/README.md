# Psionic Suppression - Always Accessible

Makes the **Psionic Suppression** technology accessible without requiring you to encounter psionic auras first.

## What This Changes

### Base Game Requirement
- **Tech:** `tech_psionic_suppression`
- **Original:** Requires Shroud DLC + `has_encountered_psionic_auras` flag
- **Problem:** You must encounter psionic auras through events/exploration before you can research the counter-technology

### This Mod's Fix
- **Removes:** `has_encountered_psionic_auras` requirement
- **Result:** Tech becomes available as soon as you have Shroud DLC
- **Still Blocked For:** Mindwardens origin (intentional by design)

## What It Unlocks

Psionic Suppression technology provides:
- **Shroud Seals:** Planetary buildings that suppress psionic auras
- **Psionic Suppressors:** Ship components for fleet defense against psionics

## Installation

1. The mod files are in: `Documents\code\Stellaris_mod\psionic_suppression_accessible\`
2. Copy `psionic_suppression_accessible.mod` to: `Documents\Paradox Interactive\Stellaris\mod\`
3. Enable in Stellaris launcher
4. Load order doesn't matter for this mod

## Compatibility

- **Requires:** Shroud DLC
- **Compatible with:** All mods, all DLC
- **Works for:** All empire types including Wilderness, Gestalts, Regular empires
- **Supported version:** Stellaris 4.x

## Why This Mod?

Sometimes you need psionic suppression tech BEFORE you've randomly encountered auras in the galaxy. This mod lets you prepare defenses proactively rather than reactively.

Perfect for:
- Defensive playstyles
- Multiplayer where you know psionic empires exist
- Roleplay as anti-psionic civilizations
- Wilderness empires that want full tech access
