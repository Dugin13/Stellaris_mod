# Imperial Branch Offices Mod

## Description
This mod allows regular (non-corporate) empires to establish branch offices on other empires' planets through an Ascension perk.

## Features
- **Diplomatic Expansion Ascension Perk**: Grants non-corporate empires the ability to establish branch offices
- Custom branch office buildings designed for regular empires:
  - **Embassy Complex**: Provides diplomatic weight and amenities
  - **Trade Hub**: Generates trade value and merchant jobs
  - **Cultural Center**: Provides amenities and unity
  - **Research Liaison Office**: Generates research and researcher jobs
  - **Industrial Outpost**: Generates alloys and consumer goods
  - **Foundry Complex**: Generates alloys only
  - **Factory Complex**: Generates consumer goods only
  - **Agricultural Complex**: Generates food and farmer jobs
  - **Energy Station**: Generates energy and technician jobs
  - **Mining Complex**: Generates minerals and miner jobs

## Compatibility
- Stellaris Version: 4.x
- Should be compatible with most other mods
- Works alongside corporate empires

## Installation
1. Subscribe to the mod on Steam Workshop or place the mod folder in your Stellaris mods directory
2. Enable the mod in the Stellaris launcher
3. Select the "Diplomatic Expansion" Ascension perk during gameplay with a non-corporate empire
