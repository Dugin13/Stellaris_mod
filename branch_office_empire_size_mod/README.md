# Branch Office Empire Size Reduction Mod

## Description
This mod adds a new Ascension perk for Megacorporations that removes the Empire size cost from branch offices.

## Features
- **Corporate Efficiency Ascension Perk**: An Ascension perk that eliminates the Empire size penalty from branch offices
- Available for Corporate and Megacorporate empires
- Perfect for players who want to expand their corporate network without administrative overhead

## Compatibility
- Stellaris Version: 4.x
- Should be compatible with most other mods

## Installation
1. Subscribe to the mod on Steam Workshop or place the mod folder in your Stellaris mods directory
2. Enable the mod in the Stellaris launcher
3. Select the "Corporate Efficiency" Ascension perk during gameplay
