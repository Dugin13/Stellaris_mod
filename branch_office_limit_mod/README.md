# Increased Branch Office Building Limit

This mod increases the maximum number of branch office buildings from 5 (vanilla) to 8.

## Features
- Increases MAX_BRANCH_OFFICE_BUILDINGS from 5 to 8
- Each capital tier now unlocks 2 branch office building slots (instead of 1)
  - Base capital (Colony Shelter): 2 slots (vanilla: 1)
  - Capital tier 1: +2 slots (vanilla: +1)
  - Capital tier 2: +2 slots (vanilla: +1)  
  - Capital tier 3: +2 slots (vanilla: +1)
- Uses scripted variables and triggered modifiers (similar to BPVR mod approach)
- Allows corporate empires to build more branch office buildings on each planet
- Applies to all corporate authorities
- Includes localization for in-game tooltips and descriptions

## Installation
Only copy the .mod file to your Stellaris mod directory:
- Copy `branch_office_limit_mod.mod` to: `%USERPROFILE%\Documents\Paradox Interactive\Stellaris\mod\`
- Enable the mod in the Stellaris launcher

## Compatibility
- Designed for Stellaris 3.x.x
- Should be compatible with most mods
- May conflict with other mods that modify MAX_BRANCH_OFFICE_BUILDINGS

## Balance Note
This gives corporate empires significantly more power through branch offices. Consider adjusting difficulty or using with other balance mods.
